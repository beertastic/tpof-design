## How far can it be trusted?

**Further than the 24A error suggests.** Checked 2026-08-01: the per-scene
`Script Page:` values in the export line up with the screenplay's own page
numbering scene for scene, all the way through. Scene 12 is on page 7 in both.
This is not an export from some wildly different draft — it is the same film, and
the disagreement is confined to how the finale is labelled.

So **the extracted element lists are worth keeping and worth trusting**: props,
set dressings, costumes and scene lengths, which Filmanize derives and the
screenplay does not list anywhere. That is the whole reason this folder still
exists. The `Costumes (1): Jedi Robes` entry on Scene 12 is a good example — it
is how the art department discovered the script named a costume there at all.

**One caveat:** the header says *Script pages: 19*, and the screenplay runs to 29.
The last two scenes in the export both start at page 19, so that figure appears to
be where the final scene begins rather than a page count. Do not schedule off it.

The Markdown files in this repository are design-development documents, not
replacements for the screenplay or Filmanize production data.
