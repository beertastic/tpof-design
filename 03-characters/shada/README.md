# Shada Production Package

This folder is a Git-ready review package for the TPOF character-board standard.

- The five PDFs are A2 landscape with crisp vector typography.
- `renders/` contains exact 7016 x 4961 PNG exports for print review and raster workflows.
- `references/` preserves the approved five-board concept preview.
- `source/` contains the rebuild script and working artwork crops.

Suggested commit:

```text
design(shada): add five-board A2 production package
```
