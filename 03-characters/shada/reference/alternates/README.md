# Alternates

Good images that no board uses.

`source/artwork/` means **images a board consumes** — the orphan check treats
anything unreferenced there as a mistake. Keep worthwhile alternates here
instead, so the input folder stays honest and nothing gets deleted as a stray.

| File | What it is |
|---|---|
| `natural_alt.png` | Camera-facing full-figure natural pose, hand on hip. Was `turn-working-natural` until 2026-07-31, when a better one replaced it — the current version has her looking away, weight settled, arms loose, which suits a character who watches rather than presents. This one is clearer on the face, so it is worth keeping for a deck cover or casting reference |
