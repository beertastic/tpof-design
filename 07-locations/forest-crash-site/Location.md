# Forest Crash Site

> Refer to the Production Design Bible before all visual development.

**The wreck of the escapees' ship.** Two kilometres from the mercenary landing
clearing, on the far side of it from the dense forest the escapees run into.

> **It is on the map and it may never be on screen.** That is the whole design
> problem with this location, and it is why it needed an entry: it is briefed in
> Scene 9, its smoke is set dressing in Scenes 24 and 25, it is where the last
> shot of the film is pointed — and there is currently no scene set there.

## Story Function

**It is a direction, not a place.** For the audience the crash site exists
entirely as a column of smoke on the horizon, seen from other locations, all day.

It does four things without ever being visited:

| | |
|---|---|
| **It starts the film** | Scene 2 puts it there before anyone has spoken |
| **It gives the mercenaries their brief** | *"Their ship crashed two clicks from here"* — Sc.9. It is the reason ten armed people are in this forest |
| **It sets the clock** | The smoke is visible to both sides. The escapees know they can be found by it |
| **It is the last thing in the film** | Baylan and Shin run toward it as it fades to black |

## Geography and Layout

Settled 2026-08-01 as part of the forest world's geography — see
[`../forest-world/Location.md`](../forest-world/Location.md), which holds the
zone diagram and the reasoning.

```
        [ THE MINES ]  ·  dampening field  ·  never seen
                 \
                  \   the escapees fly too close and stall
                   \
              [ CRASH SITE ]  ·  smoke rising all film
                     |
                     |  ~2 km
                     |
     [ LANDING CLEARING ]——————[ DENSE FOREST ]——————>
      mercenaries land here      escapees run in here
```

**The mercenaries could not set down at the wreck.** They landed two kilometres
out, at the first clearing that would hold a YT-2000. Whatever the crash site is,
**it is not somewhere a freighter can land** — the ground, the trees or the field
itself rules it out, and that is the reason the film happens on foot.

## Visual Design

**The one thing that must be designed is the smoke column**, because it is the
only part of this location any audience sees.

- **It is up for the entire film** — evening in Sc.2, still swirling the
  following morning in Sc.24 and 25. That is roughly eighteen hours of burn.
- It should therefore read as **something structural still burning**, not a
  fireball and not a smouldering scatter. Thick, dark, vertical, slow.
- **It is available as background in every exterior scene from 3 onward.** Treat
  it as part of the sky rather than an effect to be added where it is scripted —
  it is scripted in three places and true in all of them.
- Distance and scale must stay legible: it is two kilometres away, and it should
  read as reachable on foot.

**The wreck itself is undesigned**, and needs to be only if a scene goes there.

## Set Dressing

Nothing until there is a scene. If one is added, the constraints already fixed
elsewhere are:

- **Torn hull metal**, of the specific kind that impaled Jeyin — see
  [`06-vehicles/escapee-ship/Vehicle.md`](../../06-vehicles/escapee-ship/Vehicle.md).
- **Four people's absence.** They walked away from it hours ago carrying nothing.
  Whatever they abandoned is still there.
- **No bodies.** All four survived the landing.

## Lighting and Atmosphere

Sc.2 is **evening**. The smoke is seen thereafter through night (10–15) and into
morning (16–25) — so the column is lit four different ways across the film and
should be planned once rather than per scene. At night it is most likely a glow
and an absence of stars rather than a shape.

## Open

- **Does a scene ever go there?** Currently no. If the crash is filmed for Sc.2,
  this becomes a real set; if not, it stays a smoke column and this document is
  the whole of it.
- **What is still burning eighteen hours later?** Worth one decision, because it
  determines the column's character. Fuel is the obvious answer and it should not
  be an unconsidered one.
- **Do the escapees ever look back at it?** They can see it all day. Nothing in
  the script has anyone acknowledge it after Sc.9, and a single glance would cost
  nothing and carry a lot.
- **The last shot runs toward it.** Baylan and Shin leave on the mercenary ship,
  which is at the landing clearing — two kilometres the other side. Flagged under
  [`../forest-world/Location.md`](../forest-world/Location.md) and in the ship's
  document; recorded here because this is the thing they are running at.
